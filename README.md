# vdf-moment-fidelity

Calc-III Honors Project - Computational VDF and successive moment fidelity.

This project studies how finite velocity-space resolution affects the moments of a non-Maxwellian plasma distribution. The first test case is a three-dimensional Gaussian core plus a narrow drifting beam.

## Baseline

Normalized density is 1. The core standard deviation is 1, the beam standard deviation is 0.4, the beam fraction is 0.05, and its drift along x is 2. The velocity domain is [-6, 6] along each axis.

The initial goal is to verify density, bulk velocity, the second central moment, and the third central moment against the analytical Gaussian-mixture values before studying coarse grids.
